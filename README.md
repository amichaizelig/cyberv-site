# cyberv-site

האתר של **CyberV** (סייבר-וי): שירותי סייבר מנוהלים לעסקים קטנים ובינוניים.

עמוד HTML אחד בעברית (מימין לשמאל), בלי שלב build. כדי לצפות באתר, פותחים את `index.html` בדפדפן.

## מבנה

- `index.html` – כל העמוד: תוכן, עיצוב וסקריפט.
- `assets/brand/` – הלוגו של CyberV.
- `assets/clients/` – לוגואי הלקוחות.
- `.claude/` – שרת מקומי קטן לתצוגה מקדימה (`node .claude/serve.js`, ואז `http://localhost:4173`). לא חלק מהאתר.
